# 💊 Medical Insurance Cost Prediction

A Machine Learning project to predict annual medical insurance charges for individuals.

---

## 📌 Project Overview

This project uses a Medical Insurance dataset of 1,338 individuals. Using personal details like age, BMI, smoking status, and region, the goal is to predict annual insurance charges using Regression techniques.

---

## 📂 Dataset Features

| Feature | Description |
|---------|-------------|
| `age` | Age of the individual |
| `sex` | Gender |
| `bmi` | Body Mass Index |
| `children` | Number of children |
| `smoker` | Smoking status yes or no |
| `region` | Residential region |
| `charges` | Target — annual insurance cost |

---

## 🛠️ Tools & Libraries

- **Data Processing:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **ML Models:** Regression models via Scikit-Learn

---

## 🔍 Project Workflow

1. Data Loading and Exploration — 1,338 records, 7 features
2. EDA — smoking vs charges, BMI vs charges, age trends
3. Data Preprocessing — encoding categorical variables
4. Train-Test Split
5. Regression Model Training
6. Evaluation — R2 Score, MAE, RMSE
